
# How to Convert the Bedrock-Glacier Profile data and X-Y format to X_scaled-Z format

[![continuummodelnt2d](https://img.shields.io/badge/sb1-streamlit-green)]( https://bedrock-glacier-data-format1.streamlit.app/)  ( If the original glacier-bedrock profile is in Y_high to Y_low and X_low to X_high coordinates, this app will convert into X_scaled-Z format where X_scaled is in the range 0-X and Z starts from Z_low to Z_high)
